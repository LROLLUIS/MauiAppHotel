# Hotel Recanto do Sol – App Hotel (.NET MAUI)

Atividade de **Recuperação – Fichário** da Agenda 13 de Desenvolvimento de Sistemas II (ETEC – EAD):
*Imagens e Componentes Diversos de Interface Gráfica*.

## O que o app faz
Calcula o valor de uma hospedagem a partir de:
- quantidade de **adultos** e **crianças** (componente `Stepper`);
- **suíte** escolhida (componente `Picker`);
- datas de **check-in** e **check-out** (componente `DatePicker`).

Os dados são enviados para a tela de resumo usando **BindingContext**.

## Telas
1. **Contratação da Hospedagem** – formulário com Stepper, Picker e DatePicker.
2. **Hospedagem Contratada** – resumo da reserva e valor total.
3. **Sobre** *(nova)* – nome do desenvolvedor, ano de desenvolvimento e informações do app.

## Personalizações
- Nome do hotel: **Hotel Recanto do Sol**;
- nova cor principal (azul petróleo `#1B5E78`);
- cantos arredondados nos cartões e botões;
- validação: aviso se nenhuma suíte for selecionada;
- botão **Sobre o App** e nova tela **Sobre**.
